How it works

Same SDK. Different promise.

−import { usePrivy } from '@privy-io/react-auth'
+import { usePrivy } from '@lowki/react-auth'
  1. Keys on the deviceA passkey unlocks a key that lives on the user's device. The server can't sign.
  2. A wallet per appEvery app gets its own wallet and user ID. Apps can't follow users.
  3. Pay privatelyShield and withdraw through Privacy Pools (Kohaku), proved in the browser.
  4. Get paid at a namealice.lowki.eth resolves to a fresh address every time. Live on Sepolia.
